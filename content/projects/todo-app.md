## 项目背景

这是我学习的第一个完整的 React 项目。我想要创建一个实用的待办事项管理工具，帮助自己更好地规划日常学习任务。

## 技术亮点

- 使用 React Hooks 进行状态管理
- TypeScript 保证代码类型安全
- Vite 提供快速的开发体验
- Tailwind CSS 实现响应式设计
- LocalStorage 持久化数据

## 功能特性

- ✅ 添加、编辑、删除任务
- ✅ 任务分类和标签
- ✅ 完成状态标记
- ✅ 数据本地持久化
- ✅ 响应式设计，支持移动端

## 学习收获

通过这个项目，我深入理解了 React 的组件化思想，掌握了 Hooks 的使用技巧，并对前端状态管理有了更清晰的认识。
